# DNS 터널링 탐색기

보안을 처음 배우는 사람이 DNS 이름을 검사하며, **엔트로피를 낮춘 DNS 터널링은 엔트로피 하나로는 놓치고, 학습 범위에 따라 탐지율이 달라진다**는 논문 결과를 직접 확인해 보는 앱입니다.

> 합성 데이터로 만든 학습·체험용입니다. 실제 트래픽 탐지 도구가 아닙니다.

- 논문: 엔트로피를 낮춘 DNS 터널링에 대한 임계값 방식과 로지스틱 회귀 분류기의 탐지율 비교 (김경민, 2026) → [`docs/paper.pdf`](docs/paper.pdf)
- 논문 실험 저장소: https://github.com/birdmin/dns-tunnel-entropy-detection

## 열어 보기

- 웹: https://birdmin.github.io/dns-tunnel-explorer/ (로그인 없음)
- 내 컴퓨터: 이 저장소를 내려받아 `index.html`을 브라우저로 엽니다. 설치와 인터넷 연결이 필요 없습니다.

## 쓰는 방법

1. **검사**: DNS 이름을 입력하거나 예시 버튼을 눌러 네 가지 특징과 두 방식의 판정을 봅니다.
2. **학습 범위**: 같은 이름이 '높음만 학습'과 '모두 학습'에서 어떻게 달라지는지 비교하고, 논문의 단계별 재현율을 봅니다.
3. **임계값**: 슬라이더를 움직여 낮은 엔트로피 터널링을 잡으려 할수록 정상 이름의 오탐이 늘어나는 것을 봅니다.

## 논문 결과를 쓰는 곳

| 화면 | 쓰는 것 | 출처 |
|---|---|---|
| 1·2 | 로지스틱 회귀 계수와 표준화 값 (1차 '높음만 학습', 2차 '모두 학습') | 논문 실험 1회차(시드 11)의 학습 데이터로 같은 코드(`run_experiment.py`)를 다시 학습해 얻음. 시험 결과가 `metrics.csv`와 일치함을 확인 |
| 1·2 | 임계값 4.0(1차), 3.403(2차) | 논문 실험 1회차 `metrics.csv` |
| 2 | 단계별 재현율·오탐률 | 논문 표 1·표 2 (5회 평균) |
| 3 | 엔트로피 분포(0.05 간격 집계) | 논문 1차 실험 시험 데이터 5회분: 정상 2,500, 높음 2,500, 중간 5,000, 낮음 5,000건 |

슬라이더 결과는 임계값을 4.0으로 고정해 계산하므로, 회차마다 임계값이 조금씩 달랐던 논문 표 1과 소수점 단위로 다를 수 있습니다(예: 높음 단계 1.000 대 0.997).

## 데이터와 개인정보

- 앱에 들어 있는 데이터는 모두 **논문에서 규칙으로 만든 합성 데이터**의 일부이거나 그것을 집계한 값입니다. 실제 사용자 질의, 실제 응답, 개인정보는 없습니다.
- 정상 도메인 목록(Tranco)은 앱에 포함하지 않았습니다.
- 예시 이름은 합성 데이터에서 가져온 앞부분(접두사)입니다.

| 예시 | 앞부분 |
|---|---|
| 정상(일반) | `login` |
| 정상(해시형) | `53dd2ad464cfad0ca70` |
| 높음 | `h79qjfv.c40ksuahb3lvu1r.ze3wflyuly` |
| 중간 | `aa4j412ppa2540jplji5vvwj4vv1wl1pqq00.0` |
| 낮음 | `erpj.dxeddeceppedrxrxdjeexr0` |

- 입력한 이름은 브라우저 안에서만 계산하며 저장하거나 전송하지 않습니다. 서버, 로그인, 쿠키, 외부 요청이 없습니다.

## 환경 변수와 비밀값

**필요한 환경 변수가 없습니다.** 이 앱은 AI 서비스나 외부 서버를 호출하지 않아 키와 비밀값이 없습니다. 소스에서 `fetch`, `XMLHttpRequest`, `key`, `token`, `secret`, `password`를 검색해 없음을 확인했습니다.

## 한계

- 모든 데이터가 합성이어서 실제 DNS 트래픽에서도 같은 결과가 나온다고 말할 수 없습니다.
- 분류기는 특징 네 개(엔트로피·길이·숫자 비율·레이블 개수)를 쓰는 로지스틱 회귀 하나입니다.
- 입력한 이름에서 마지막 두 칸을 등록 도메인으로 보고 뺍니다. `co.kr`처럼 등록 도메인이 두 칸이 아닌 이름은 앞부분이 다르게 잘릴 수 있습니다.
- 학습 데이터의 길이는 최대 40자여서, 더 긴 이름은 참고용입니다.
